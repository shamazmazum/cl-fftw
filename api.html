Core constants (cl-fftw/core package):

+forward+
Designates a forward Fourier transform
+backward+
Designates an inverse Fourier transform

Management of plans. Here and below you can choose cl-fftw/double and/or cl-fftw/single package:

with-fft-plan((plan dimensions sign) &body body)
Create an FFT plan and make sure it is destroyed when control leaves body.
with-rfft-plan((plan dimensions) &body body)
Create an RFFT (real-valued input forward FFT) plan and make sure it is destroyed when control leaves body.
with-irfft-plan((plan dimensions) &body body)
Create an IRFFT (real-valued input inverse FFT) plan and make sure it is destroyed when control leaves body.

Basic FFT functions:

fft(plan array)
Perform FFT transform. array's and plan's dimensions must be the same.
rfft(plan array)
Perform RFFT (real-valued input forward FFT) transform. array's and plan's dimensions must be the same.
irfft(plan array)
Perform IRFFT (real-valued input inverse FFT) transform. array's dimensions must be compatible with plan's dimensions.

"Convenient" FFT functions (no plan creation required, save typing):

%fft(array sign)
Perform FFT transform. This is a version of FFT without previously created plan.
%rfft(array)
Perform RFFT (real-valued input forward FFT) transform. This is a version of RFFT without previously created plan.
%irfft(array dimensions)
Perform IRFFT (real-valued input inverse FFT) transform. This is a version of IRFFT without previously created plan.
